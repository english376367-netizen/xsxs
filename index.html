Volunteer & Community Service

Sentence Building & Sentence Rewriting

1. Make sentences using the words and phrases below

(Tạo câu sử dụng các từ và cụm từ phía dưới. Hãy nhớ thay đổi cấu tạo của một số từ.)
Công thức cần nhớ:
• find + O + adjective → find something interesting
• can + V nguyên mẫu → can meet
• to + V → chỉ mục đích: to help
• because + S + V → chỉ nguyên nhân
• need to + V → need to be
• If + hiện tại đơn, S + can/might + V
1. Minh / find / volunteer activities / interesting / can meet / new people.
Correct answer: Minh finds volunteer activities interesting and can meet new people.
Giải thích: Với find + O + adjective: finds volunteer activities interesting. Sau can dùng động từ nguyên mẫu: can meet.
2. We / join / community activities / help / needy / last summer.
Correct answer: We joined community activities to help needy people last summer.
Giải thích: Last summer → quá khứ đơn: joined. Dùng to + V để chỉ mục đích: to help needy people.
3. We / learn / teamwork skills / when / join / some / clean-up activity / last summer.
Correct answer: We learned teamwork skills when we joined some clean-up activity last summer.
Giải thích: Last summer → learned, joined. Cấu trúc: learn + something + when + S + V.
4. If you / love / nature / can / join / our Green Neighbourhood project.
Correct answer: If you love nature, you can join our Green Neighbourhood project.
Giải thích: Câu điều kiện: If + hiện tại đơn, S + can + V nguyên mẫu. Vì chủ ngữ là you nên dùng love.
5. I / join / recycling project / because / want / help / protect / environment.
Correct answer: I joined the recycling project because I wanted to help protect the environment.
Giải thích: Động từ ở quá khứ: joined, wanted. Cấu trúc want to + V → wanted to help; help + V → help protect.
6. You / need / patient and caring / when / take care of / pets.
Correct answer: You need to be patient and caring when you take care of pets.
Giải thích: Cấu trúc need to + V → need to be. Sau when dùng mệnh đề: when you take care of pets.

2. Rewrite the following sentences so that their meaning stays the same

(Viết lại các câu dưới đây để nghĩa không thay đổi. Sử dụng từ cho sẵn.)
Công thức cần nhớ:
• If + S + V hiện tại đơn, S + might/can + V
• might + V nguyên mẫu
• because + mệnh đề
• S + V, and + S + V
• The number of + danh từ số nhiều + is increasing
1. My school may hold some volunteer activities. I am thinking about joining the animal care project. (IF)
Correct answer: If my school holds some volunteer activities, I might join the animal care project.
Giải thích: If + hiện tại đơn → If my school holds.... might + V nguyên mẫu → might join.
2. Raising funds for poor children is one thing you may do. (MIGHT)
Correct answer: You might raise funds for poor children.
Giải thích: might + V nguyên mẫu diễn tả “có thể”. Vì vậy dùng might raise.
3. She doesn't join any volunteer activities. She says she is busy. (BECAUSE)
Correct answer: She doesn't join any volunteer activities because she says she is busy.
Giải thích: Dùng because + mệnh đề để nối nguyên nhân: because she says she is busy.
4. My parents often go to villages to do charity work. I go with them. (AND)
Correct answer: My parents often go to villages to do charity work, and I go with them.
Giải thích: Dùng and để nối hai mệnh đề. Sau and vẫn có chủ ngữ + động từ: I go.
5. There are more and more volunteer organisations in the country. (INCREASING)
Correct answer: The number of volunteer organisations in the country is increasing.
Giải thích: Cấu trúc: The number of + danh từ số nhiều + is increasing. Chủ ngữ chính là the number nên dùng is.
